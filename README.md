# SpaceQ

**AI Solutions Architect**

Инженерные продукты для промышленности, технической документации и анализа данных.  
Всё работает локально или в закрытом контуре клиента: данные наружу не уходят.

---

## Продукты

### DocCore

Платформа для завода, развёртывается на стороне заказчика (on-prem). Оператор работает в браузере, данные в облако не уходят.

Три модуля:

1. **Перевод чертежей** (RU↔EN): PDF или DXF на входе, PDF с подписями на своих местах на выходе.
2. **Перевод документов** (RU↔EN): TXT, DOC, DOCX, PDF на входе, DOCX или PDF с сохранённой вёрсткой на выходе.
3. **LegalModule**: проверка договора по чек-листу заказчика. Юрист видит найденный пункт и его текст или «не найдено», решение остаётся за ним. Результат выгружается в Excel.

### SpaceFlow

Локальная система на Go и Python для поиска апериодических и морфологически странных событий в открытых данных NASA (TESS, наблюдения Солнца).

Контур целиком: от кривой блеска до короткого списка кандидатов, с очередью, веб-панелью и уведомлениями в Telegram. Всё на localhost.

Качество измеряется на тестовом стенде с инъекциями сигналов. Сейчас ведём ночные прогоны и шорт-лист кандидатов.

### CORE BREACH

Локальная white-hat консоль внешней поверхности атак (EASM).

Три слоя: пассивный OSINT (без обращений к цели), анализ поверхности, углублённая проверка.

Только ресурсы, на которые у оператора есть право обзора. Эксплуатации и подбора паролей нет.

### Kinematics

Локальный движок скелетного трекинга и биомеханического разбора видео.

Направление: горные лыжи и сноуборд. Офлайн, без отправки видео в облако. Windows / Linux сейчас, Android позже.

На выходе: скелет, углы, качество сигнала, оверлей, JSON/CSV.

В плане: 3D-просмотр, анатомический слой с подсветкой зон нагрузки (оценка, не измерение), сравнение проездов.

Статус: в разработке, кода ядра ещё нет.
