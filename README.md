# SpaceQ

**AI Solutions Architect**

Локальные и on-prem AI-системы enterprise-уровня.  
Данные клиента остаются у клиента. Не SaaS. Не «чат с LLM». Законченный контур: вход → обработка → результат для оператора.

Направления:
- enterprise-обработка технической и юридической документации;
- поиск аномалий в научных данных;
- white-hat EASM и защита внешней поверхности атак;
- биомеханика и скелетный разбор движения по видео.

Рабочий код-private. Здесь-портфолио продуктов.

## DocCore

**Enterprise-платформа** интеллектуальной обработки технической и юридической документации. On-prem: данные в контуре заказчика, оператор в браузере. Архитектура модульная-текущие модули не предел, платформа рассчитана на расширение.

| Модуль | Вход | Результат |
|--------|------|-----------|
| Перевод чертежей | PDF (CAD/скан), DXF | PDF с подписями на своих местах (RU↔EN) |
| Перевод документов | TXT, DOC, DOCX, PDF | DOCX / PDF с сохранённой вёрсткой (RU↔EN) |
| LegalModule | DOCX | проверка договора по чек-листу заказчика → Excel; решение за юристом |

**Архитектура.** FastAPI + worker + изолированные пайплайны модулей; LLM on-prem (vLLM / Ollama). LegalModule-отдельный сервис со своим LLM и SSO в общую платформу. Без модели система не падает: словарный MOCK-режим.

**Статус.** В промышленной эксплуатации у заказчика. Код закрытый.

## SpaceFlow

**Локальная anomaly-платформа** на Go + Python для поиска апериодических и морфологически странных событий в открытых данных NASA (TESS SPOC) и канале наблюдений Солнца.

Классический BLS ловит периодические провалы. SpaceFlow заточен под то, что периодический поиск теряет: жёсткое вето, контроль FPR, короткий список кандидатов — не «шум ради модели».

Контур целиком на одной машине:
- предобработка кривых → детект (боевой профиль ens4) → FDR → вето известных объектов и приборных артефактов;
- очередь, веб-панель (Anomaly Deck), Telegram — `localhost`.

**Измерение.** Стенд с инъекциями: recall и FPR против базовых методов, composite-скор. Без полного вето «уникальную находку» не объявляю.

**Статус.** Космо-ядро собрано и работает сутками (демон + worker). Тот же контур «аномалия → вето → очередь → метки» готов к трансформации в промышленный anomaly-модуль — отдельный трек.

## CORE BREACH

**Локальная white-hat EASM-платформа** для защиты от кибератак: непрерывный анализ внешней поверхности атак (External Attack Surface Management) без облака и без деструктивного воздействия на цели.

Движок и сессии — на машине оператора. Только авторизованный scope. Слои контроля:

| Слой | Суть |
|------|------|
| OSINT ONLY | пассивная разведка, без TCP/HTTP к цели |
| Surface | инвентаризация хостов, портов и веб-активов в scope |
| Deep / Active | краулер, фаззер, Nuclei — только с явным режимом и PIN |

**Дисциплина.** Нет эксплуатации и подбора паролей. Чужой периметр не трогается, пока оператор сам не расширит scope. Находки MEDIUM+ — только после ручной верификации, не по слову модели.

Стек: Python, NiceGUI, локальный runtime.

**Статус.** Платформа в работе; OSINT / Surface обкатаны на живых целях в своём scope.

## Kinematics

**Локальный движок** скелетного трекинга и биомеханического разбора видео. Направление: горные лыжи и сноуборд, далее — шире. Без облака, без привязки к Apple. Windows / Linux сейчас, Android — следующий этап.

На выходе: скелет, углы, качество сигнала, оверлей, машинные данные (JSON/CSV). Сравнение проездов в UI.

**Целевой пайплайн.** Ingest (FFmpeg/OpenCV) → поза (RTMPose ONNX / запас BlazePose) → сглаживание и углы → экспорт. Дальше: 3D-просмотр и анатомический слой с подсветкой зон нагрузки как **оценки**, не как ЭМГ.

**Принцип.** При анализе видео сеть не используется.

**Статус.** В разработке: ТЗ и документация готовы, кода ядра ещё нет. Следующий шаг — спайк FPS / точности позы на реальных клипах.
