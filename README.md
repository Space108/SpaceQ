# SpaceQ

**AI Solutions Architect**

Строю локальные и on-prem AI-системы: данные клиента остаются у клиента.  
Не SaaS и не «просто чат с LLM» — законченные контуры под задачу: от входа файла или сигнала до результата для оператора.

Фокус:
- промышленная документация и юридическая проверка договоров;
- поиск аномалий в научных данных;
- white-hat анализ внешней поверхности атак;
- биомеханика и разбор движения по видео.

Рабочий код — в private-репозиториях. Здесь — портфолио продуктов.

## DocCore

**Задача.** На заводе нельзя гонять чертежи и договоры в облачный переводчик. Нужен свой контур: оператор в браузере, данные на сервере заказчика.

**Что это.** On-prem IDP-платформа с тремя модулями под одной оболочкой:

| Модуль | Вход | Результат |
|--------|------|-----------|
| Перевод чертежей | PDF (CAD/скан), DXF | PDF с подписями на своих местах (RU↔EN) |
| Перевод документов | TXT, DOC, DOCX, PDF | DOCX / PDF с сохранённой вёрсткой (RU↔EN) |
| LegalModule | DOCX | чек-лист завода по договору → Excel; юрист решает сам |

**Как устроено.** FastAPI + worker + пайплайны модулей; LLM на стороне завода (vLLM / Ollama). LegalModule — отдельный сервис со своим LLM, SSO в общую платформу. Без модели система не падает: есть словарный MOCK-режим.

**Статус.** Платформа в боевом контуре заказчика. Код закрытый.

## SpaceFlow

**Задача.** Классический поиск планет ловит периодические провалы. Апериодические и морфологически странные события в кривых блеска легко теряются — нужен отдельный контур с жёстким вето и измерением ложных срабатываний.

**Что это.** Локальная гибридная система **Go + Python** на одной машине:
- данные: открытые архивы NASA (TESS SPOC) + канал наблюдений Солнца;
- детект ансамблем (боевой профиль ens4), FDR, вето известных объектов и приборных артефактов;
- очередь задач, веб-панель (Anomaly Deck), Telegram — всё на `localhost`.

**Чем измеряю.** Стенд с инъекциями сигналов: recall и FPR против базовых методов, отдельный composite-скор. Без полного вето «уникальную находку» не объявляю.

**Статус.** Космо-ядро собрано и крутится сутками (демон + worker). Трансформация того же контура «аномалия → вето → очередь → метки» в промышленность — отдельный трек.

## CORE BREACH

**Задача.** Нужна операторская консоль внешней поверхности атак без облака и без «чёрного» инструментария: только свой scope, только то, на что есть право обзора.

**Что это.** Локальная white-hat EASM / BB-консоль (Python, NiceGUI):

| Слой | Суть |
|------|------|
| OSINT ONLY | пассивная разведка, без TCP/HTTP к цели |
| Surface | хосты, порты, веб в рамках scope |
| Deep / Active | краулер, фаззер, Nuclei — только с явным режимом и PIN |

**Правила.** Нет эксплуатации и подбора паролей. Чужой домен не сканируется, пока оператор сам не расширит scope. Находки уровня MEDIUM+ — после ручной проверки, не «ИИ сказал».

**Статус.** Консоль в работе, слои OSINT / Surface обкатаны на живых целях в своём scope.

## Kinematics

**Задача.** Инструктору нужен разбор движения по видео без облака и без привязки к Apple: скелет, углы, оверлей, сравнение проездов.

**Что это.** Локальный движок скелетного трекинга и биомеханики. Направление: горные лыжи и сноуборд, дальше — шире.

**Целевой контур.** Ingest (FFmpeg/OpenCV) → поза (RTMPose ONNX / запас BlazePose) → сглаживание и углы → JSON/CSV + оверлей → UI сравнения. Дальше: 3D-просмотр и анатомический слой с подсветкой зон нагрузки как **оценки**, не как ЭМГ.

**Принцип.** При анализе видео сеть не используется.

**Статус.** В разработке: документация и ТЗ есть, кода ядра ещё нет. Ждём клипы и спайк по FPS / точности позы.
